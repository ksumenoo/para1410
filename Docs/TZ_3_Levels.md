# Чат 3 — Уровни (4 ключевые локации)

Сначала прочитай `Docs/CORE_API.md` и план друга `Docs/План локаций — Наоборот получилось.docx` (раздел 5, планы комнат). Пиши ТОЛЬКО в `Assets/_Echo/Editor/Levels/` (и `Assets/_Echo/Levels/` для материалов/префабов мебели). Namespace `Echo.Levels`.

## Как
Один редакторский класс с методом
```csharp
[Echo.EditorTools.EchoLevelBuilder]
public static void BuildLine(EchoBuildContext ctx, Transform lineRoot, int line)
```
Он вызывается дважды (line 1 и 2) при *Echo → Собрать сцену прототипа* и заменяет тестовый коридор. Геометрия обеих линий **одинаковая** (те же координаты), отличается материалами/декором: линия 1 — чистая, линия 2 — разруха, зелёное свечение, завалы (завалы могут перекрывать проход — это геймплей, но путь к цели на линии 2 должен существовать или открываться предметом/дверью с линии 1).

Уровень — последовательность локаций вдоль +X (пол y=0, стены высотой 3 м с BoxCollider, проходы ≥ 2.5 м — для NavMesh). Порядок и задачи — из плана друга:
1. **Лобби** (публичная зона, голубая полоса): ресепшен, экспозиция, турникет, служебный коридор. Ключ-карта на ресепшене (`ItemMarker Key, keyId=1`) → дверь в служебный коридор (`DoorMarker doorId=1 keyId=1`). Охранник патрулирует служебный коридор (`GuardMarker` + точки).
2. **Служебная зона** (жёлтая полоса): опенспейс, кабинет начальника (красная карта `Key keyId=2`), раздевалка с рюкзаком (`Backpack`) и шкафчиками (`LockerSpot` + визуал шкафа), 2 охранника, 2 бочки. Дверь на лестницу к реактору (`doorId=2 keyId=2`).
3. **Реакторный уровень −1** (красно-белая разметка): высокий реактор (`ReactorMarker` на «звезде» перед ним), 2 военных (`GuardMarker soldier=true`), ящики-укрытия. Чекпоинт перед реактором.
4. **Нижние лаборатории + зал аппарата** (объединить): стеклянный коридор (стекло — слой 2 Ignore Raycast, с коллайдером), крио-склад с картой `keyId=3`, дверь `doorId=3`, зал с аппаратом (`MachineMarker`). На линии 1 после сопряжения здесь ходит Герой 2 — 1 военный. Пистолет Героя 1 (`Pistol`) и патроны (`Ammo`) положить на **линии 2** во второй половине уровня (после реактора).
- `CheckpointMarker` в начале каждой локации (на линии 1).
- Метки мутантов/сгустков (`MutantMarker`, `TimeClotMarker`) — их делает Чат 2; когда появятся, расставь на линии 2 (2–4 на локацию). До этого оставь в коде TODO.
- Цветовые полосы зон вдоль стен (отдельный тонкий бокс 0.25 м высотой).
- Таблички на русском — можно `TextMesh` (3D), не обязательно.

Визуал: пока цветные боксы/цилиндры + материалы URP Lit. Текстуры друг положит в `Assets/Art/Textures/tex_<набор>_<floor|wall>_L1|L2.png` (наборы: lobby, office, tech, hitech) — подхвати их, если файл есть, иначе цвет.

Камера смотрит сверху под 50°, видно ~20×12 м вокруг героя — потолков не делать, стены не выше 3 м.

## Готово, когда
Сцена собирается, в «Один ПК» можно пройти лобби → служебную зону → реактор (сопряжение) → лаборатории → аппарат на обеих линиях; ключи/двери/охрана работают; NavMesh не рвётся (охрана ходит по маршрутам). Компиляция без ошибок.
